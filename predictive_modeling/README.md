# Predictive Modeling Module

An independent, optional module for building predictive models on ICU patient data processed by the CRISP pipeline.

## Overview

This module implements both traditional machine learning and deep learning models (future) for predicting ICU outcomes such as mortality and length of stay. It's designed to work seamlessly with the data produced by the CRISP pipeline but operates independently.

## Features

### Traditional Machine Learning Models
- **Logistic Regression**: Baseline linear model with L2 regularization
- **Random Forest**: Ensemble method with feature importance
- **Gradient Boosting**: Sequential boosting for improved performance  
- **XGBoost**: State-of-the-art gradient boosting implementation
